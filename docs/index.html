API de reservas de pistas deportivas

Documentación de la especificación OpenAPI 1.3.0. Es una API de práctica para pruebas de contrato; el repositorio con las pruebas y las reglas de negocio está en GitHub.

Las reglas que OpenAPI no expresa (horario, solapes, límites por usuario y cancelación) están en la sección "Reglas de negocio" del README.

Probar desde esta página: las peticiones de "Try it out" van a http://localhost:3000. Solo funcionan si tienes el servidor levantado en tu equipo (npm run server).
