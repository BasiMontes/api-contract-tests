API de reservas de pistas deportivas

Reto de contrato de API: una API de práctica con su especificación OpenAPI como fuente de verdad, y pruebas que comprueban que el servidor cumple lo que promete.

En curso OpenAPI 1.3.0 Node 24 Playwright + TypeScript

Las reglas que OpenAPI no expresa (horario, solapes, límites por usuario y cancelación) están en la sección "Reglas de negocio" del README, junto con el repositorio de las pruebas.

Cómo probar las reservas desde esta página

  1. Levanta el servidor en tu equipo: npm run server.
  2. Regístrate con POST /auth/registro (email, contraseña de 8 o más caracteres y nombre).
  3. Obtén el token con POST /auth/login. Copia solo el valor de token, sin comillas.
  4. Pulsa Authorize arriba a la derecha y pega el token. Swagger añade el prefijo Bearer solo.

Probar desde esta página: "Try it out" envía las peticiones a http://localhost:3000. Solo funciona si tienes el servidor levantado (npm run server).
